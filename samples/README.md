# Sample logs

`qad-client-test.log` is a synthetic QAD/OpenEdge client log (LOG-MANAGER format: 4GLTrace, 4GLMessages,
DB.Connects, FileID, QryInfo) for trying out ProTrace Analyzer. It is generated by `generate-test-log.py`.

| PID | Scenario | What to look for |
| --- | --- | --- |
| 4812 | PO maintenance (`popomt.p` → `popomta.p` → `popomtb.p` → `validate-part`) | `(91)` No pt_mstr record, then `(142)`; later `(132)` duplicate item and `(138)` not on file in `ppptmt.p` |
| 5120 | SO maintenance (`sosomt.p`) | 3 × `(2624)` record-lock waits, then `(915)` lock table overflow and `(142)` |
| 6044 | Batch inventory transfer (`iclotr.p` → `ictrancr.p`) | ~1,280 fast trace lines, `(5407)` -nb warning, `icrecalc.p` takes ~4.5 s |
| 7233 | Report (`rcrprp.p`) | `(293)` program not found, `(3135)` invalid widget-id, then `SYSTEM ERROR (49)` with an ABL stack dump |
